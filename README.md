# Email-Digest
Automated Email processing and concluding program based on DeepSeek API

# Structure
## EmailDigest.ipynb 
Key file for running. Set a daily windows trigger directing to this file.
## EmailDigest.py
Backup of the .ipynb file.
## my_profile.json
Sent to LLM as part of the prompt. Contains personal description, portrait, preferences.
## my_profile.txt
Backup of the .json file
